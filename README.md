# Paris Metro History

The most complete open-source historical database of the Paris Métro.

## Goal

This project aims to reconstruct the Paris Métro network for any date between 1900 and today.

The database contains:

- Metro lines
- Stations
- Platforms
- Sections between stations
- Opening dates
- Extensions
- Renamed stations
- Closures
- Historical events
- Sources

The data is designed so that an application can reconstruct the exact network for any given date.

Example:

```js
getNetwork("1937-01-01");
```
